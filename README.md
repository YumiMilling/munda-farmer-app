# Munda Farmer App

A Progressive Web App for farmers to manage crops, track weather, and monitor market prices — works offline.

## Getting Started

```bash
npm install
npm run dev
```

## Features

- Offline-first PWA (installable on mobile)
- Crop tracking & management
- Weather forecasts & alerts
- Market price monitoring
- Task management

## Tech Stack

- React + Vite
- Service Worker for offline support
- PWA manifest for installability
